# Information
Started on May 3rd, 2025, the Super Smash Bros. Idea is a videogame that started development after the release of 'Personal Projects'. with the goal of introducing myself to the world of game development and setting the bases for a more ambitious and similar project.

The project is a 2D fighting game that takes inspiration from the Super Smash Bros. series.

A refactoring of the project was made on August 2026, the time this repository was created, to improve the code and make it more organized and readable.

# How to use

## Requirements
[ Godot 4.7 ]( https://godotengine.org/ ) is required to start working in this project.  

## Editor
The project is ready to be run in the Godot editor.
